Good to know.

Clear answers about access, data and the app download.

Does Spendly read my SMS messages?

No. Spendly does not request SMS access. Optional Notification Access can read payment alerts from supported apps locally so it can suggest transactions.

Do I need to enable permissions?

No account is needed. Usage Access and Notification Access are optional Android settings that support automatic detection. You can also enter expenses yourself.

Where is my financial data stored?

On your device in an encrypted database. Spendly has no internet permission or cloud sync.

Which Android versions are supported?

Android 10 and newer.

What will the download install?

The file linked here is Spendly v1.0.0’s local debug APK (about 80 MB), not a Play Store release. Android may ask you to allow installation from your browser or file manager. Only install an APK you trust.
